Instalación en Android

1

Para instalar esta aplicación, primero necesitas descargar el instalador base desde el repositorio oficial:

Descargar Aplicación de Instalación
2

Una vez instalada la aplicación anterior, ábrela y selecciona el paquete de Clase WEB que has recibido para completar la integración.

Si encuentras algún error durante el proceso, asegúrate de haber permitido la instalación de aplicaciones de orígenes desconocidos en los ajustes de tu teléfono.
